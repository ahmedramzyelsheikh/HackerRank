## 🌟 About

This repository holds my solutions to the **HackerRank Problem Solving** track, written in **C++** and **C**. It's how I practice algorithms, data structures and clean code.

**Topics covered**

| Area | Examples |
|---|---|
| 🔥 Warm-up & implementation | Simple sums, time conversion, grading, counting |
| 🔤 Strings | Anagrams, alternating characters, binary strings |
| 📊 Arrays | 2D arrays, array manipulation, rotations |
| 🔗 Linked lists | Insert, delete, reverse, merge, compare |
| 🧱 Stacks | Balanced brackets |
| 🧮 Sorting | Insertion sort and other sorting challenges |
